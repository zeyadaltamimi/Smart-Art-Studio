# فيديو موشن جرافيك — متجر الفن الذكي

فيديو ترويجي إعلاني مبني بـ [Remotion](https://www.remotion.dev) (React).

| | |
|---|---|
| **المقاس** | ١٠٨٠ × ١٩٢٠ (عمودي ٩:١٦ — مناسب للريلز والتيك توك والستوري) |
| **معدل الإطارات** | ٣٠ إطار/ثانية |
| **المدة** | ٧٣٥ إطار = **٢٤.٥ ثانية** |
| **الخطوط** | Cairo للعناوين، Tajawal للنصوص المساندة (تُحمّل تلقائياً) |

اخترنا المقاس العمودي لأن النص يقول «رابط المتجر في البايو»، وهذه صيغة إنستقرام/تيك توك.
لتغيير المقاس عدّل `width` و `height` في `src/Root.tsx` (مثلاً ١٠٨٠×١٠٨٠ للمربع، أو ١٩٢٠×١٠٨٠ للأفقي).

## التشغيل

```bash
cd video
npm install
npm run dev      # يفتح استوديو Remotion للمعاينة والتعديل المباشر
```

## التصدير

```bash
npm run render   # ينتج out/smart-art-promo.mp4
```

أو لإطار واحد فقط للمعاينة السريعة:

```bash
npx remotion still SmartArtPromo out/frame.png --frame=300
```

المشاهد متداخلة قليلاً لأن كل انتقال (١٥ إطار) يشغّل المشهدين معاً.

### المعالجة البصرية

- **المشهدان ١ و ٢** بألوان باردة (كحلي/رمادي داكن): الكلمات تظهر تدريجياً ثم تهتز اهتزازاً بسيطاً يعبّر عن الاستياء، وفي المشهد الثاني تتكرر بطاقات أغانٍ **متطابقة تماماً** في الخلفية لتجسيد التشابه الممل.
- **الانتقال إلى المشهد ٣** سريع ومبهج (انزلاق من الأسفل بحركة نابضة) مع انفجار حلقتين ضوئيتين وتحوّل كامل إلى الذهبي والبيج الداكن.
- **المشاهد ٣ و ٤ و ٥** دافئة وفخمة: توهج ذهبي، بريق متلألئ، نوتات موسيقية تتطاير، ونصوص بتدرّج ذهبي.
- **المشهد ٥** يجمع الشعار والسهم المتحرك نحو البايو وشارة «متجرنا سعودي وموثّق» باللون الأخضر السعودي.

## التعديل

كل النصوص والألوان والحركات مكتوبة **داخل `style`** مباشرة، أي يمكن تعديلها بصرياً من داخل استوديو Remotion (اضغط على أي عنصر ثم عدّل قيمه أو مفاتيح الحركة)، ويُكتب التعديل في الكود تلقائياً.

- **النصوص**: مكتوبة نصاً صريحاً داخل كل مشهد في `src/scenes/`.
- **مدة أي مشهد**: `durationInFrames` في `src/SmartArtPromo.tsx` (وكذلك في `src/Root.tsx` لمعاينة المشهد منفرداً). عند تغييرها، حدّث مدة `SmartArtPromo` في `src/Root.tsx`:
  `المجموع = مجموع مدد المشاهد − (عدد الانتقالات × ١٥)`
- **الألوان الذهبية**: `#F7DFA5` (فاتح) و `#E8B75A` (أساسي) و `#C9973F` (غامق)، والخلفيات الدافئة `#4A3520` و `#33241A` و `#241A12`.

## الشعار

الشعار الحالي **مؤقت** ومبني بالكود في `src/components/Logo.tsx` (دائرة ذهبية + نوتة + اسم المتجر).
لاستخدام شعار المتجر الحقيقي:

1. ضع ملف الشعار في `public/logo.png`
2. استبدل `<Logo size={330} />` في `src/scenes/Scene05Cta.tsx` بـ:

```tsx
import {CanvasImage, staticFile} from 'remotion';

<CanvasImage src={staticFile('logo.png')} style={{width: 330, height: 330}} />
```

## الموسيقى (خطوة مقترحة)

الفيديو حالياً **بلا صوت**. لإضافة موسيقى خلفية:

```bash
npx remotion add @remotion/media
```

ثم ضع الملف في `public/music.mp3` وأضفه في `src/SmartArtPromo.tsx`:

```tsx
import {Audio} from '@remotion/media';
import {staticFile} from 'remotion';

<Audio src={staticFile('music.mp3')} durationInFrames={735} volume={0.7} />
```

احرص على استخدام موسيقى مرخّصة للاستخدام التجاري.
